# Pepcalculator

PepCalculator: installable offline-first web app that turns a desired peptide dose into the syringe amount. Not medical advice.

## Stack
React + Vite + TypeScript PWA (`src/`), Vitest.

## Commands
- `npm run dev`
- `npm run typecheck`
- `npm test`: Vitest
- `npm run build`

## Where things are
Read `HANDOFF.md` first: architecture, decisions, gotchas and roadmap.
- Decisions: `docs/decisions/` (one file per decision; read the relevant one before changing pricing, features, legal or architecture).
- New one-off scripts go in `scripts/`; reports in `docs/reports/`; plans in `docs/plans/`. Nothing new in the repo root.
