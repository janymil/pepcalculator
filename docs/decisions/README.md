# Decisions

One file per decision: `YYYY-MM-DD-<short-slug>.md`. Newest wins; an outdated one gets
`Status: superseded by <file>`. Claude Code loads this list at the start of every session.

```
# <Decision in one line>
Date: YYYY-MM-DD · Status: decided | proposed | superseded by <file>
## Context
## Decision
## Why
## Consequences / next steps
```
